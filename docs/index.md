# Industries & Verticals

Domain-specific toolkits and ISV integrations for AMD Instinct™ GPUs, covering computer vision, data science, life
science, finance, and simulation/modeling applications. For core ROCm software and API documentation, see the
[ROCm documentation](https://rocm.docs.amd.com). For deploying and operating AMD Instinct GPUs at scale, see the
[AMD Instinct Systems & Infrastructure documentation](https://instinct.docs.amd.com).
