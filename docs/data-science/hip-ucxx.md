# hip-ucxx

hip-ucxx is AMD's HIP/ROCm port of UCXX, an object-oriented C++ interface to UCX with native Python bindings for
GPU-direct communication on AMD Instinct™ GPUs. It supports tag matching, active messages, and stream-based
communication over InfiniBand, ROCm-IPC/XGMI, shared memory, and TCP, along with a Dask Distributed backend —
serving as the low-level communication layer beneath other AMD Data Science components such as dask-hip.
